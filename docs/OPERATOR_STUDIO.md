# Quản trị nhà xe — Laravel

Nhánh hiện tại đã thay backend Node bằng Laravel. Tất cả hướng dẫn cài đặt,
chức năng, app nhiều nhà xe và DNS/SSL nằm tại [LARAVEL_PORTALS.md](LARAVEL_PORTALS.md).

Bản Node cũ được giữ trên nhánh `feature/operator-studio` để đối chiếu, không chạy
song song hoặc dùng chung file DB với Laravel. Không dùng hướng dẫn Node cũ cho
nhánh Laravel này.
